# P3 preregistration: static/dynamic correlation

- Packet: `PKT-SYNTH-P3-0001`, schema 1
- Static routes: Python AST decorator/function return values plus the pinned
  JSON table.
- Dynamic route: one process each for `ALPHA`, `OMEGA`, and rejected
  `UNKNOWN`.
- Preferred mechanism: marker/table entries predict runtime tags and values.
- False mechanism: function names are runtime tags.
- Negative gates: wrong fixture hash and parent-mismatched observation ID both
  preserve registry bytes and root.
- Scope: known-source synthetic protocol qualification only; no MC2 inference.

`P3.json` is the normative machine-readable packet.
