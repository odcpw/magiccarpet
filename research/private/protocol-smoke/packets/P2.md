# P2 preregistration: competing timing laws

- Packet: `PKT-SYNTH-P2-0001`, schema 1
- Preferred law: `ticks = floor(sum(deltas_ms) / 20)`.
- Alternative: `ticks = callback_count`.
- Primary contrasts: one `55 ms` callback and partitioned `5,15,20 ms`.
- Rejection control: a negative delta is rejected, while the prescribed run
  remains experimentally valid.
- Acceptance requires a `CRITICAL` timing/determinism finding; a
  `SIMPLE_BOUNDED` candidate must fail without changing the registry.
- Scope: known-source synthetic protocol qualification only; no MC2 inference.

`P2.json` is the normative machine-readable packet.
