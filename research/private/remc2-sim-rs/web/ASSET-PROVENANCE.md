# Browser vignette asset provenance

This directory is an owner-local private Track P prototype. Nothing here is a
release or redistribution package.

## Generated presentation assets

| File | Origin | Intended use |
| --- | --- | --- |
| `design/concept.png` | OpenAI image generation, 2026-07-24 | Internal visual target for the golden-hour carpet-flight vignette |
| `public/assets/carpet-texture.png` | OpenAI image generation, 2026-07-24 | Newly generated carpet surface used by the browser prototype |

The generation brief asked for an original golden-hour fantasy archipelago,
an erupting volcano, an ornate flying carpet, and a sparse brass-and-glass HUD.
It did not request or ingest any original Magic Carpet 2 image asset.

All terrain geometry, beacons, vegetation, clouds, smoke, water, particles,
HUD elements, and audio in the runnable scene are generated procedurally by
project code. No owned MC2 DAT/TAB art or original audio is packaged by the
browser build.
