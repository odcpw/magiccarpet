## Closure contract (measurable; replaces "matching decomp" language)

Level 1 conformance is **closed** exactly when all of the following hold:

1. remc2 at the pinned commit is the sole specification; evidence for locally
   modified files comes from `git show 6806c72:<path>`.
2. Every mechanically reachable Level 1 behavior is a row in the canonical
   matrix (census reconciliation: 308 authored rows partitioned across AUT-*
   index lists; 177-entity reset census bound to RST-003; every dispatch slot
   of every reachable class present as a DSP row or covered by an EXC proof).
3. No reachable row is `Partial`, `Missing`, `Wrong`, or `Unproved`.
4. Every `Exact` row carries source anchors plus executable evidence bindings
   that the validator (PLAN-01) resolves against the real test inventory; a
   test-name string that does not resolve fails the gate.
5. Every exclusion has a mechanical reachability proof (EXC-*); the
   conditional class-10 slots in DSP-10-COND are resolved either way by
   PLAN-25 before closure.
6. `remaining_resident_behavior_mask == 0` and the legacy mission mask
   stays `0`; no new gap register is nonzero.
7. `level1_p0_ready()` returns true and its successor exhaustive gate —
   `level1_matrix_closed()` (added by PLAN-01/PLAN-29), true only when the
   regenerated matrix contains zero non-Exact reachable rows — returns true.
8. From a clean state (`cargo clean` + fresh Unity import + rebuilt owner
   cache), the full gate set passes under the final one-run policy:
   `cargo fmt --check`, the recorded non-increasing Clippy ceiling,
   `cargo test --workspace --locked` (unit/integration/property),
   sim-capi ABI tests, owner-cache validation (17 checks + negatives),
   reference-corpus checks, Unity EditMode + PlayMode, built-player route and
   post-completion route with digest equality across two sessions, lifecycle/
   privacy negatives, and the provenance boundary scan.
9. No fixture asserted against remc2-source behavior is generated by the
   implementation under test; preserved DOS frames, pinned-native GDB
   checkpoints, and owner data are the only state oracles, and source-derived
   vectors are constructed from the cited line spans.
10. The playable mission loop is exercised end to end including acquisition,
    combat, resident/house/castle behavior, village-expansion groups,
    objective completion, failure/restart, and Unity presentation handoff.

All ten contract points are validated by the canonical matrix and the final
PLAN29 Run-A receipts. The final qualification policy supersedes the earlier
two-run wording without weakening any behavioral gate.
